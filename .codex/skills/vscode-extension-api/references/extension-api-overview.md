# Extension API Overview

This reference summarizes the documentation supplied when the skill was created.

## Core Idea

Visual Studio Code is built for extensibility. Much of the UI and editing experience can be customized through the Extension API, and many core VS Code features are implemented as extensions using the same API.

## Documentation Areas

- Build, run, debug, test, and publish extensions.
- Use the VS Code Extension API and its capability areas.
- Follow extension guides and code samples.
- Apply VS Code UX guidelines for extension user experience.
- Use official references for the VS Code API, contribution points, and advanced topics.

## Common Extension Capabilities

- Change VS Code's appearance with color themes or file icon themes.
- Add custom workbench components and views.
- Create webviews with custom HTML, CSS, and JavaScript.
- Support new programming languages.
- Support debugging for a specific runtime.
