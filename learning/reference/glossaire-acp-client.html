Glossaire rapide

Termes canoniques · source : src/core/CONTEXT.md

Agents

ConfiguredAgent
Entrée dans l'arbre — depuis settings ou pipeline virtual.
ConnectedAgent
Le seul processus agent actuellement lancé (un à la fois).

Conversation & persistance

Conversation
Fil interactif en direct dans le panneau chat.
ProtocolSession
Identifiant et capacités côté agent ACP.
SessionRecord
Fiche locale dans l'arbre (titre, agent, Discussion optionnelle).
NewConversation
Nouvelle ProtocolSession, chat visible effacé — ≠ ouvrir un ancien record.

Deux « historiques »

ChatHistory
État UI riche : outils, réflexion, markdown, blocs pipeline.
Discussion
Texte plat borné sur SessionRecord — handoff et familles de contexte.

Transport

nativeAcp
Processus ACP sur l'hôte.
sandcastle
Bridge vers agent isolé dans Docker + worktree.
virtual
Orchestration LangGraph in-process (pipelines / teams).

Exécutions éphémères

EphemeralRun
Spawn temporaire pour une étape pipeline ou une édition inline — n'occupe pas le slot ConnectedAgent.
OrchestrationRun
Run d'un VirtualAgent — apparaît comme une Conversation normale.

Piège « session »

Toujours qualifier :

  1. ProtocolSession — id agent
  2. Conversation — fil courant
  3. SessionRecord — ligne dans l'arbre
  4. BridgeConversation — paire bridge Sandcastle (Sandcastle seulement)
